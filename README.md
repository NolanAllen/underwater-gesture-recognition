# Underwater Gesture Recognition
By Nolan Allen

This project, developed for CSCI S-89 Deep Learning at Harvard, follows the development and training of a convolutional neural network (CNN) that categorizes diver gestures from camera data.

The dataset used to train this model can be found [here](http://www.caddian.eu//CADDY-Underwater-Gestures-Dataset.html). There are 16 gestures in total given by divers in underwater settings. The final CNN model uses three convolutional layers with almost 10 million trainable parameters. The highest-achieving model scored 50% accuracy on the validation set, demonstrating clear learning and generalization capabilities. To achieve higher accuracy, I believe it would be necessary to use a pre-trained model to achieve better learning with the current dataset.

For a more detailed and thorough analysis, please see the embedded presentation video below and the final project report in this repository. Additionally, the source code is available in this repository in a Jupyter Notebook.
